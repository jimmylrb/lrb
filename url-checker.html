📖 本工具检测哪些特征？

  • 🔴 ⚡ 使用 IP 地址代替域名
  • 🔴 🔗 使用 URL 缩短服务（如 tinyurl、bit.ly）
  • 🔴 🌐 可疑的顶级域名（.xyz、.top、.club 等）
  • 🔴 🔀 域名中存在混淆字符（数字 1 代替字母 l、0 代替 o 等）
  • 🔴 🔓 非 HTTPS 连接
  • 🔴 🏢 知名品牌名称出现在子域名或路径中（而非主域名）
  • 🔴 📏 异常长的 URL
