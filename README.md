# 🛡️ 网络安全意识培训 — 钓鱼攻击识别

> **免责声明：** 本网站为**合法的安全教育项目**，仅用于提高公众对钓鱼攻击的防范意识。**不收集任何用户数据**，所有输入仅在用户浏览器本地运行。请勿将其中展示的技术用于非法目的。

## 项目结构

```
phishing-awareness/
├── index.html      # 首页 — 钓鱼攻击科普知识
├── demo.html       # 交互式模拟 — 仿冒邮件/页面拆解演示
├── quiz.html       # 知识测验 — 8道场景识别题
├── guide.html      # 防护指南 — 最佳实践和应急措施
├── style.css       # 全局样式
├── script.js       # 通用交互（提示气泡）
└── quiz.js         # 测验数据和逻辑
```

## 使用方法

直接用浏览器打开任意 `.html` 文件即可，无需构建或安装依赖。

推荐访问顺序：
1. **首页** — 了解钓鱼攻击的基础知识
2. **模拟演示** — 查看交互式的钓鱼案例拆解
3. **知识测验** — 测试你的识别能力
4. **防护指南** — 学习如何保护自己

## 技术栈

纯 HTML + CSS + JavaScript，零依赖，零第三方库。
