✅ 交互式安全检查工具

收到可疑消息时，逐项勾选检查，帮你快速判断是否安全。

收到一封可疑邮件？逐项勾选以下检查项：

✓
发件人地址与官方域名一致（如 @xxbank.com，不是 @xxbank-security.net）
✓
没有使用"紧急"、"立即"、"否则将被冻结"等制造紧迫感的措辞
✓
邮件中没有要求点击链接进行"验证"、"更新"账户信息
✓
邮件中没有拼写错误或奇怪的语法
✓
将鼠标悬停在链接上，显示的地址与链接目标一致
✓
附件是你预期中的文件（不是意外的 .exe、.zip、.docm 等）
✓
收件人地址没有异常（检查 BCC 是否包含陌生人）

收到一个可疑链接？逐项勾选以下检查项：

✓
链接使用 HTTPS（https://，不是 http://）
✓
域名中没有混淆字符（如 1 代替 l、0 代替 o、rn 代替 m）
✓
不是 IP 地址代替域名（如 http://192.168.x.x）
✓
不是 URL 缩短服务（tinyurl、bit.ly 等）
✓
顶级域名无异常（不是 .xyz、.top、.club 等可疑域名）
✓
品牌名出现在主域名中，而不是子域名或路径中
✓
链接中没有 @ 符号

接到一个可疑电话？逐项勾选以下检查项：

✓
来电号码不是"+"开头的境外号码（如 +1、+85 等）
✓
对方没有要求你下载任何 App 或开启"屏幕共享"
✓
对方没有索要验证码、密码、银行卡号等敏感信息
✓
没有以"退款"、"取消会员"、"调整利率"等借口要求你操作
✓
没有自称"公检法"要求你配合调查
✓
没有要求你"不要告诉家人/不要挂断电话"
✓
你能通过官方渠道（官网电话、官方 App）核实来电身份

收到一个可疑的 App 下载请求？逐项勾选以下检查项：

✓
从官方应用商店（App Store、华为应用市场等）下载
✓
不是通过网页弹窗、短信链接或扫码下载
✓
开发者信息清晰可查，不是个人开发者
✓
下载量正常（不是下载量个位数的新 App）
✓
用户评价真实（不是全五星好评但内容通用）
✓
App 申请的权限合理（如手电筒 App 不需要读取通讯录）
✓
不是通过"免费领"、"扫码送"等渠道诱导下载

💡 使用提示

✅ 每个项目中，勾选的越多说明越安全
✅ 如果大部分项目无法勾选，请提高警惕
✅ 任何勾选了 "没有……" 类项目的，都是安全信号
❌ 即使所有项都通过，也请保持警惕 — 骗子手段不断翻新
